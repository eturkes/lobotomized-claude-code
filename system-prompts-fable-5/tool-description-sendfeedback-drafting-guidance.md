Draft feedback about Claude Code (the product) at a high-signal moment: a reproducible tool or product failure just resolved or abandoned, the user clearly frustrated with Claude Code itself, or a missing capability that blocked a reasonable request. Never mid-task as a question.

The draft is queued locally and renders no UI — continue the task silently rather than announcing it.

One draft per distinct issue per session. Keep secrets, credentials, and personal information out of the title and details.
